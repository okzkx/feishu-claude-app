## 问题分析

### 当前错误
- **错误位置**: `MainPage.tsx:539`
- **错误信息**: `加载图片失败: 图片请求失败: HTTP 404 Not Found`
- **调用链**: `handleLoadImage` → `get_feishu_image` Tauri 命令

### 根本原因
1. **类型不匹配**: 后端 `get_feishu_image` 返回 `Result<Vec<u8>, String>`，前端期望 `number[]`
2. **404错误**: 飞书图片 API 返回 404，可能原因：
   - image_key 无效或过期
   - Token 权限不足
   - 图片已被删除

## 修复方案

### 阶段一：类型修复 (高优先级)
1. **修复前端调用**
   - 将前端 `invoke<number[]>` 改为正确处理 `Result<Vec<u8>, String>`
   - 添加错误处理逻辑

2. **增强后端错误处理**
   - 添加更详细的错误信息
   - 实现 Token 刷新机制
   - 添加图片 Key 验证

### 阶段二：API 优化 (中优先级)
1. **Token 管理**
   - 实现自动刷新 Token
   - 缓存 Token 减少请求

2. **图片缓存**
   - 实现前端图片缓存
   - 避免重复请求

### 阶段三：测试验证 (高优先级)
1. **单元测试**
   - 测试图片加载功能
   - 测试错误处理

2. **集成测试**
   - E2E 测试图片显示
   - 测试各种边界情况
