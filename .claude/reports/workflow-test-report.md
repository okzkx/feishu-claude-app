E2E 测试的完整执行需要以下环境：
1. **安装 tauri-driver**: `cargo install tauri-driver`
2. **下载 Edge WebDriver**: 版本需匹配系统 Edge 版本
3. **构建 Release 版本**: `npm run tauri build`
4. **运行驱动**: `tauri-driver --native-driver <path-to-msedgedriver>`
5. **执行测试**: `npx wdio run wdio.conf.ts`
